# Generated Root Cause Analysis Reports

All investigation reports approved by engineers on the EOPS Studio dashboard are generated here as Markdown documents.

Each report is named using the pattern:
`RCA_[INVESTIGATION_UUID].md`

These reports include:
1. Incident description and metadata.
2. Formulated root cause hypothesis.
3. Quantifiable evidence metrics (logs, Git diffs).
4. Concrete remediation steps.
5. Reference articles.
