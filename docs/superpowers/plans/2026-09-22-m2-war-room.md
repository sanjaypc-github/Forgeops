# M2 War Room Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** The War Room: a pixel-art office where each agent sits at a desk, works when the backend says so, walks to a colleague's desk when it asks a question, pins evidence to a wall, and a side chat bar where the user reports a problem, follows the investigation, approves or rejects actions and asks follow-ups.

**Architecture:** A pure reducer turns the SSE event stream into `OfficeState` (agents' modes and locations, plan, evidence, RCA, chat, approval). The office renders a static tile layer (Kenney Tiny Town CC0 tiles + code-drawn office furniture) on one canvas, and characters as absolutely positioned pixel sprites (MIT portrait engine adapted from Munder Difflin, new ForgeOps recipes) that walk along aisle waypoints with CSS transforms. Text (names, bubbles, chat) is real DOM for crispness and accessibility; a screen-reader live region narrates events.

**Spec:** TRD §12, PRD §7, PRODUCT.md. Visual direction: user-chosen asset route (pixel office from Kenney Tiny Town + procedural characters), professional with character, not game-like chrome: pixel art is confined to the floor; all UI around it is crisp.

## Global constraints
- Office motion only from real events; replay after refresh gives the same final state; `prefers-reduced-motion` disables walking animation (instant moves).
- No runtime mock data; fixtures only in tests.
- Kenney Tiny Town CC0 (credit optional, given on the Credits line); Munder Difflin portrait engine MIT (notice kept in the file and in Credits).
- WCAG 2.2 AA: contrast, keyboard access to every control, visible focus, live-region narration.

## Tasks
1. **Backend `GET /api/agents`**: desks with title, area, capabilities and connected connectors (from connection rows + catalog tool mappings). Test.
2. **Assets**: copy the Tiny Town packed tilemap + license into `frontend/src/war-room/assets/`; tile index map (`tiles.ts`).
3. **Characters**: port `portraitArt.ts` (MIT header) with ForgeOps recipes per agent + the human approver; `spriteCanvas()` helper. Test: every agent has front/back frames of the right size.
4. **Floor plan**: `layout.ts` — map size, desk positions per agent, special spots (whiteboard, evidence wall, RCA board, approval desk, door), aisle waypoints; `routeBetween(a, b)` returns waypoints. Tests.
5. **Office reducer**: `officeState.ts` — `applyOfficeEvent(state, event)`, pure. Tests from event fixtures (plan, tools, questions walk there and back, evidence, failure, RCA, approval, actions, completion, replay idempotence).
6. **Tile renderer**: `FloorCanvas.tsx` draws floor/walls/props/desks at integer scale; desk furniture drawn in code.
7. **Characters on the floor**: `Agent.tsx` sprite + name plate + status lamp + bubble; walking along waypoints; reduced-motion.
8. **War Room page**: office + chat bar + evidence detail sheet + incident header/timer; home route with office idle state and "What's broken?" composer; `/investigations/:id` live.
9. **Chat bar**: messages from events, RCA card, approval card (select recommendations, approve/reject/investigate more), follow-ups; tests with mocked fetch.
10. **Report page** (react-markdown, no raw HTML) + history page tidy; credits line.
11. **Verify**: build, tests, detector, browser check with a replayed event log fed through the reducer in the browser console (debug only), screenshots desktop + mobile.
